# Stonecross UI kit

Parchment, engraved iron and heraldic gold UI for Crown & Crucible. Everything here is
generated by code, so it can be rebuilt or retuned at any time.

```bash
/path/to/venv/bin/python art_src/ui/gen_ui.py     # needs Pillow + numpy
```

That one command writes:

| Output | What it is |
|---|---|
| `art_src/ui/png/*.png` | Every sprite frame, already at GUI scale (`<sprite>_<frame>.png`) |
| `art_src/ui/manifest.json` | Sprite names, frame files, size, origin and 9-slice margins (GUI px) |
| `scripts/ui_kit_data/ui_kit_data.gml` | Generated GML: font advance tables, 9-slice margins, `UI_ICON_*` / `UI_ITEM_*` macros, discipline and rarity tables |
| `art_src/ui/preview/*.png` | 1366x768 mock-ups (HUD + dialogue, plain dialogue, Armory in socket and card focus, kit sheet) |

The generator doesn't touch `BLANK GAME.yyp`, objects, rooms, `sprites/` or `generate_sprites.py`.

`gen_screens.py` writes the menu-screen art (goods, seals, crests) straight into the project and
refreshes the two Pixelify fonts after `GLYPH_FIX` changes (the source font's 5 reads as an S).
Hold `/tmp/cc_yyp.lock` while it runs.

## Art rules

* 1 art px = 2 GUI px (`SCALE = 2`), which matches the 2x world camera. Exception: the
  `small` and `title` font sprites are drawn at 1x so they stay legible.
* Light comes from the top-left. Outlines are dark, hue-shifted purple-browns (around `#261824`), never pure black.
* The palette is warm and saturated with no pure black or white. The one exception is font
  glyphs, which are white so the draw colour can tint them.
* No emoji anywhere: icons are `spr_ui_icons` frames.

## Importing (main thread)

* Import each manifest entry as a sprite with the listed frames, in order, and the listed origin.
  Most origins are top-left; `spr_ui_medallion` is centred.
* **Leave GameMaker's own Nine Slice option off.** `ui_nine()` slices manually using the
  margins in `ui_kit_data()`, so that it works the same on every sprite and in the preview.
* **Turn texture interpolation off when drawing the UI.** `options_mac.yy` has
  `option_mac_interpolate_pixels: true`, which blurs pixel art. Either untick it, or call
  `gpu_set_texfilter(false)` at the top of Draw GUI.
* Add these scripts to the `.yyp`: `ui_kit_data`, `ui_kit`, `ui_text`, `ui_hud`, `ui_dialogue`, `ui_equipment`.

## Card disciplines and rarity

Each discipline has its own socket **shape** as well as its own colour, so the screen reads
without relying on colour alone.

| Index | Discipline | Socket shape | Colour | Emblem |
|---|---|---|---|---|
| 0 | STRENGTH | Bastion square | Ember orange | War hammer |
| 1 | FINESSE | Diamond | Violet | Rapier |
| 2 | QUICK | Hexagon | Azure | Lightning bolt |
| 3 | LUCK | Circle | Green | Clover |
| 4 | HEALTH | Cross pattée | Red | Heart |
| 5 | SHIELD | Heater shield | Steel | Heraldic shield |
| 6 | WILD | Eight-point star | Gold | Sparkle |

Rarity tiers 0..4 are COMMON (iron), UNCOMMON (bronze, green gems), RARE (silver, blue),
EPIC (gold, violet) and LEGENDARY (gold with crimson inlay, amber). Rarity shows in the frame
metal, the number of gems on the card foot (tier + 1), and corner rivets from Rare up. Cards
and gear without a `rarity` field are drawn as Common. `ui_rarity_index()` accepts a number or a name.

## GML API (GUI space, 1366x768)

| Function | Purpose |
|---|---|
| `ui_text_draw(x, y, str, style, color, max_width = -1, max_chars = -1, tracking = 0)` | Sprite-font text. Style is `body`, `small` or `title`, optionally with `_shadow` or `_outline` (use `body_outline` or `small_outline` for world name labels). It word-wraps to `max_width`, `max_chars` reveals text typewriter-style, and it returns the height of the whole wrapped block. |
| `ui_text_width(str, style)` / `ui_text_center_y(cy, style)` | Measure text, or get the y that centres capitals on `cy` |
| `ui_hud_draw(game)` | Compact top-left plate (12,10 to 384,102): level, name, HP bar, gold, time of day, party shields |
| `ui_dialogue_draw(text, speaker, portrait_or_-1, visible_chars, alpha)` | Bottom box (y 598 to 756) with a 64x64 portrait drawn at 2x and a nameplate. Alpha also slides the box up as it fades in |
| `ui_equipment_draw(game)` | The Armory. If scr_equipment_cards is loaded (`cards_catalog`, `armory_focus`), it draws gear, sockets, a paged card collection and the active build. Otherwise it draws a restyled gear sheet |
| `ui_panel(kind, x, y, w, h)` | `parchment`, `dark`, `gilded`, `gilded_dark`, `inset`, `inset_dark` |
| `ui_nine`, `ui_fill`, `ui_bar`, `ui_icon`, `ui_divider`, `ui_button`, `ui_keycap` | Building blocks |
| `ui_socket_draw(x, y, kind, state)`, `ui_card_draw(x, y, kind, rarity, name, text)`, `ui_item_slot_draw(x, y, item, slot, state, size)` | Equipment and card pieces |

The Armory only reads data: `weapons_owned` / `armors_owned` / `relics_owned`, `eq_*_idx`,
`stat_*`, `item.slots[] = { kind, card_id }`, `cards_catalog[] = { id, name, kind, desc, effects }`,
`cards_owned`, and `armory_row/slot/card/focus/notice`. Input and rules stay in scr_equipment_cards.
