# Alternate (Phase 5) art for 8 townsfolk

Claude's in-place Phase 5 session and Claude's PR #1 (claude/chronicles-greenmere) each drew Brand, Cecily, Grim, Guy, Mallow, Malo, Mira and Vane independently, with the same sprite names.
When PR #1 was merged on 2026-10-30, the PR versions were kept in sprites/ and art_src/characters/<name>/ (they match the PR's canon pass and headless QA).
The Phase 5 versions (source PNGs and defs) are preserved here so nothing is lost. To switch a character back, copy its files over art_src/characters/<name>/ and defs/<name>.json and re-run art_src/characters/import_new.py.
