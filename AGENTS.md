# Crown & Crucible (GameMaker project "BLANK GAME")

- Project root: ~/GameMakerProjects/BLANK GAME/ (project file: `BLANK GAME.yyp`). GameMaker 2024.14.4.222 on macOS (Apple Silicon).
- Code: `objects/` (each object's events are .gml files next to its .yy), `scripts/` (e.g. `scr_art_engine`), `rooms/` (`Room1`).
- Art: `sprites/` is generated by `generate_sprites.py` (Pillow) in the project root, which also registers sprites in the .yyp; source assets/fonts in `art_src/`.
- If you add a resource by hand, also add it to `resources` in `BLANK GAME.yyp`, or GameMaker won't see it.
- To look at the game: open the project in GameMaker (`open -a GameMaker "BLANK GAME.yyp"`), have Eli press Run (F5), then take a screenshot with `screencapture -x /tmp/game.png` and view it.
- Don't touch the older projects "Retro Game" or "Blank Pixel Game" in ~/GameMakerProjects/.
- Always update both canonical project documents whenever changing systems, narrative, quests, or features: `CROWN_AND_CRUCIBLE_MASTER_DOSSIER.md` (Master Project Dossier) and `docs/STORY_BIBLE.md` (Story Bible & Writer's Room).
- Design dossier: https://cursor.com/canvas/store-2b8b5867-b370-4ed9-aca2-16759203e59d/25747c48-34b9-4f33-9766-726bc4c3cb83

## Running a build without crashing the runner
- GameMaker is signed in; use the user folder `~/Library/Application Support/GameMakerStudio2/elilentz6_5139243` for Igor `--uf`.
- Never launch `Mac_Runner` on a `game.ios` unless `options.ini` (and `splash.png`) from the same Igor build sit in the same folder. Without `options.ini` the runner segfaults in `IniFile::GetSection` and macOS pops a crash dialog.
- Use `~/GameMakerProjects/_build/` for test runs and kill the runner (`pkill -f Mac_Runner`) when done.

### More runner and project-file rules (added Oct 29, 3 PM ET)
- Always launch the runner with `-game ~/GameMakerProjects/_build/game.ios`, with `options.ini` and `splash.png` next to it. Never launch the runner bare, never open `~/gamemakerstudio2/GM_MAC/BLANK_GAME/YoYo Runner.app` directly, and never launch with a missing or unbuilt `game.ios`. That pops up a 127.0.0.1 "Download" dialog for Eli. Close it when done with `pkill -f Mac_Runner`.
- Room `.yy` instance entries use `"isDnd"` (lowercase d); objects and scripts use `"isDnD"`. After editing any `.yy` or `.yyp`, run an Igor build to confirm GameMaker can load it before you finish. A wrong key makes the IDE refuse to open the project.
